Module 7.2: Neural Breakdown

Introduction

And now folks, we get down to it. The piece de resistance of 21st century statistics: neural networks.

I have debated long and hard on how to present this topic. As a mathematician, I like theory and there is A LOT of linear algebra going on under the hood, but I don’t want to get caught up in those details1. So let’s not start there.

There are A LOT of predefined functions and workflows. We could just learn them and be done with it. But then you don’t get any insights beyond the black box so I don’t really want to start there either.

Short of outsourcing this to 3Blue1Brown (which I do highly recommend you watch), the starting place I have decided on is decision boundaries. We talked about this topic back in Module 3 with logistic regression so we’ll begin with a review of what type of decision boundaries arise in such models and then discuss when they fail.

Linear Decision Boundary

As usual, we’ll begin with some fake data generated in the following way

  • Class A observations have two independent features \(X_1, X_2\), both drawn from a normal distribution with mean -1 and std.dev =1
  • Class B observations have two independent features \(X_1, X_2\), both drawn from a normal distribution with mean 1 and std.dev =1

The following code generates 250 observations for each class:

library(tidyverse)
set.seed(1015)
class_colors = c("A" = "#E35205", "B" = "#004080")

n_per_class = 250
sd = 1
fake_data=rbind(
    data.frame(
      x1 = rnorm(n_per_class, -1, sd),
      x2 = rnorm(n_per_class, -1, sd),
      class = "A"
    ),
    data.frame(
      x1 = rnorm(n_per_class, 1, sd),
      x2 = rnorm(n_per_class, 1, sd),
      class = "B"
    ) 
  )|>
    mutate(class = factor(class, levels = c("A", "B")))

ggplot(fake_data, aes(x1, x2, color = class)) +
  geom_point(alpha = 0.7) +
  scale_color_manual(values = class_colors) +
  coord_equal() +
  labs(
    x = "X1",
    y = "X2",
    color = "Class"
  ) +
  theme_minimal()

Notice that in this case, the boundary between the two classes, though blurred in many ways, is basically linear; I could draw a line which would roughly separate the two clusters. This line can be found using logistic regression.

First, we fit the model which to remind you takes the following commands:

fake_glm = glm(
  class ~ x1 + x2,
  data = fake_data,
  family = binomial
)

Notice here that the “positive” class is B; the logistic model spits out the probability that an observation fits into this class. We classify an observation as B when its estimated probability exceeds 0.5, and as A otherwise.

We can plot the decision boundary using code similar2 to what we did in Section 3.2:

plot_boundary=function(model,data){
  grid = expand_grid(
      x1 = seq(min(data$x1) - 0.5, max(data$x1) + 0.5,
             length.out = 250),
      x2 = seq(min(data$x2) - 0.5, max(data$x2) + 0.5,
             length.out = 250)
    )

  preds=predict(model, newdata = grid, type = "response")
  grid$pred_class = if_else(preds > 0.5, "B", "A")
  grid = grid |>
      mutate(pred_class = factor(pred_class, levels = c("A", "B")))

  ggplot() +
    geom_raster(
      data = grid,
      aes(x1, x2, fill = pred_class),
      alpha = 0.2
    ) +
    geom_point(
      data = data,
      aes(x1, x2, color = class),
      alpha = 0.7
    ) +
    scale_fill_manual(values = class_colors) +
    scale_color_manual(values = class_colors) +
    coord_equal() +
    labs(
      x = "X1",
      y = "X2",
      color = "Observed class",
      fill = "Predicted class"
    ) +
    theme_minimal()
}
plot_boundary(fake_glm,fake_data)

The background colors show the predicted class. The boundary between the two regions is where the model assigns probability 0.5 to Class B and as we showed in Module 3, is given by the equation of a line.

Because of this, the predictive accuracy of our model will be strong. To demonstrate, let’s do a training-testing split and calculate predictions on the test set:

n=nrow(fake_data)
s=sample(n,0.7*n)
train=fake_data[s,]
test=fake_data[-s,]

train_glm = glm(
  class ~ x1 + x2,
  data = train,
  family = binomial
)

calculate_accuracy=function(model,data){
  y=data$class
  preds=predict(model,data,type="response")
  yhat= ifelse(preds>0.5,"B","A")
  cat("Accuracy:",sum(yhat==y)/nrow(data))
}

calculate_accuracy(train_glm,test)
Accuracy: 0.9066667

Not too shabby.

Nonlinear decision boundary.

Now to create a more challenging problem. This time, Class A observations lie inside a disk centered at the origin, while Class B observations lie in a surrounding ring3. The classes are separated by a circular boundary rather than a straight line:

n_per_class = 250
inner_radius = 1
ring_inner = 1.15
ring_outer = 2.5 

make_disk = function(n, r_min, r_max, label) {
    angle = runif(n, 0, 2 * pi)
    radius = sqrt(runif(n, r_min^2, r_max^2))

    data.frame(
      x1 = radius * cos(angle),
      x2 = radius * sin(angle),
      class = label
    )
  }

disk_data=bind_rows(
  make_disk(n_per_class, 0, inner_radius, "A"),
  make_disk(n_per_class, ring_inner, ring_outer, "B")
) |>
  mutate(class = factor(class, levels = c("A", "B")))


ggplot(disk_data, aes(x1, x2, color = class)) +
  geom_point(alpha = 0.7) +
  scale_color_manual(values = class_colors) +
  coord_equal() +
  labs(
    x = "X1",
    y = "X2",
    color = "Class"
  ) +
  theme_minimal()

Let’s try and refit a logistic model to our data and look at both the decision boundary:

n=nrow(fake_data)
s=sample(n,0.7*n)
disk_train=disk_data[s,]
disk_test=disk_data[-s,]


disk_glm = glm(
  class ~ x1 + x2,
  data = disk_train,
  family = binomial
)

plot_boundary(disk_glm,disk_train)

and accuracy:

calculate_accuracy(disk_glm,test)
Accuracy: 0.6466667

That’s pretty bad!

The reason is that logistic regression cannot enclose the inner disk with a straight line. This is not just a problem in how we estimated coefficients,its a limitation of the model structure.

How do we fix it?

Well, knowing that the problem is circular, we could engineer a new variable representing distance from the origin:

\[ r = \sqrt{X_1^2 + X_2^2} \]

Let’s take a look at logistic regression with this feature explicitly thrown in there:

disk_train = disk_train |>
  mutate(r = sqrt(x1^2 + x2^2))

disk_test = disk_test |>
  mutate(r = sqrt(x1^2 + x2^2))

disk_glm_radius = glm(
  class ~ r,
  data = disk_train,
  family = binomial
)

plot_radius_boundary = function(model,data) {
  grid = expand_grid(
    x1 = seq(min(data$x1) - 0.5, max(data$x1) + 0.5,
             length.out = 250),
    x2 = seq(min(data$x2) - 0.5, max(data$x2) + 0.5,
             length.out = 250)
  ) |>
    mutate(r = sqrt(x1^2 + x2^2))

  grid$p_B = predict(model, newdata = grid, type = "response")
  grid$pred = factor(
    if_else(grid$p_B > 0.5, "B", "A"),
    levels = c("A", "B")
  )

  ggplot() +
    geom_raster(
      data = grid,
      aes(x1, x2, fill = pred),
      alpha = 0.2
    ) +
    geom_contour(
      data = grid,
      aes(x1, x2, z = p_B),
      breaks = 0.5,
      color = "black",
      linewidth = 1
    ) +
    geom_point(
      data = data,
      aes(x1, x2, color = class),
      alpha = 0.7
    ) +
    scale_fill_manual(values = class_colors) +
    scale_color_manual(values = class_colors) +
    coord_equal() +
    labs(
      title = "Classification boundary from the radius model",
      x = "X1",
      y = "X2",
      fill = "Predicted class",
      color = "Observed class"
    ) +
    theme_minimal()
}

plot_radius_boundary(disk_glm_radius,disk_train)
calculate_accuracy(disk_glm_radius,disk_test)
Accuracy: 1

That is quite an improvement in accuracy! This model can learn a circular decision boundary because the squared-distance feature is nonlinear in the original predictors.

Where neural networks come in…

The issue is that with real data, you might not be able to see a clear circular structure like you can in this fake example and instead need your algorithm to find it for you. That’s where a neural network helps us out. Instead of manually constructing a squared-distance feature, we let the model learn intermediate features from the original predictors.

A neural network contains a series of hidden units which try to “learn” patterns in the data before passing these patterns off to logistic regression (or a similar type of “activation function”) to use as features. In other words, it engineers its own features for the model.

The nnet package in R contains some basic features for fitting neural networks to data. We’ll start with 8 hidden units (size = 8):

library(nnet)
disk_nn = nnet(
  class ~ x1 + x2,
  data = disk_train,
  size = 8
)

The hidden units combine the original predictors using learned weights and apply nonlinear activation functions. The output layer uses these learned features to predict the class.

plot_boundary_nn=function(model,data){
  grid = expand_grid(
      x1 = seq(min(data$x1) - 0.5, max(data$x1) + 0.5,
             length.out = 250),
      x2 = seq(min(data$x2) - 0.5, max(data$x2) + 0.5,
             length.out = 250)
    )

  grid$pred_class = predict(model, grid, type = "class")
  grid = grid |>
      mutate(pred_class = factor(pred_class, levels = c("A", "B")))

  ggplot() +
    geom_raster(
      data = grid,
      aes(x1, x2, fill = pred_class),
      alpha = 0.2
    ) +
    geom_point(
      data = data,
      aes(x1, x2, color = class),
      alpha = 0.7
    ) +
    scale_fill_manual(values = class_colors) +
    scale_color_manual(values = class_colors) +
    coord_equal() +
    labs(
      x = "X1",
      y = "X2",
      color = "Observed class",
      fill = "Predicted class"
    ) +
    theme_minimal()
}
plot_boundary_nn(
  disk_nn, 
  disk_train
)

Unlike logistic regression on the original predictors, the neural network learned the nonlinear decision boundary all by its own self. It even gets close to 100% accuracy.

y=disk_test$class
yhat= predict(disk_nn,disk_test,type="class")
cat("Accuracy:",sum(yhat==y)/nrow(disk_test))
Accuracy: 0.9933333

Slow…clap.

Experimenting with the network architecture

What happens when we change the number of hidden units?

fit_network = function(size, data) {
  nnet(
    class ~ x1 + x2,
    data = data,
    size = size,
    trace=FALSE
  )
}

nn_2 = fit_network(2, disk_train)
nn_4 = fit_network(4, disk_train)
nn_8 = fit_network(8, disk_train)
nn_16 = fit_network(16, disk_train)

plot_boundary_nn(nn_2,disk_train) +
  labs(title="Size = 2")
plot_boundary_nn(nn_4,disk_train) +
  labs(title="Size = 4")
plot_boundary_nn(nn_8,disk_train) +
  labs(title="Size = 8")
plot_boundary_nn(nn_16,disk_train) +
  labs(title="Size = 16")

Compare the resulting boundaries and test accuracies.

Questions to consider:

  1. Does increasing the number of hidden units always improve test accuracy?
  2. Which models produce the smoothest or most complicated decision boundaries?
  3. Why does a neural network need a nonlinear activation function?
  4. What is the difference between manually adding a nonlinear feature and learning intermediate features in a neural network?

Summary

We have seen three approaches to classification:

  • Logistic regression: learns a linear decision boundary from the original predictors.
  • Feature engineering: allows logistic regression to learn nonlinear boundaries when we provide a useful transformation.
  • Neural networks: learn intermediate features through hidden layers and nonlinear activation functions.

The central idea is that hidden layers give a neural network the ability to learn useful representations of the predictors, rather than requiring us to specify every nonlinear feature in advance.
